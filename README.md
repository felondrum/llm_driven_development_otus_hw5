# LLM-приложение с мониторингом производительности и RAG системой

Приложение для анализа и мониторинга производительности LLM-систем с использованием Langfuse.

## Архитектура

### Основные компоненты

1. **RAG Система** (`rag_system.py`) - Поиск и генерация ответов на основе документов
2. **Чат-бот** (`chatbot.py`) - Консольный интерфейс для взаимодействия с пользователем
3. **Мониторинг** (`monitoring.py`) - Интеграция с Langfuse для отслеживания метрик
4. **Конфигурация** (`config.py`) - Настройки приложения

### Сущности мониторинга

- **Traces** - Полный путь выполнения запроса через систему
- **Spans** - Отдельные операции (поиск в БД, вызов LLM)
- **Generations** - Специальные spans для LLM вызовов с метаданными
- **Events** - Точечные события (загрузка файла, ошибки)
- **Scores** - Метрики качества и производительности

## Что отслеживается

### Обязательно
- ⏱️ Время выполнения операций (latency)
- 📥📤 Входные и выходные данные
- 💰 Использование токенов и стоимость

### Дополнительно (для RAG)
- 📄 Количество найденных документов
- 🎯 Релевантность результатов поиска
- 📊 Длина исходного запроса и итогового ответа

## Установка

### 1. Запуск инфраструктуры (Docker)

```bash
docker-compose up -d
```


Сервисы:
- **Langfuse Web**: http://localhost:3000
- **Ollama**: http://localhost:11434
- **PostgreSQL**: localhost:5432
- **ClickHouse**: localhost:8123
- **Redis**: localhost:6379
- **MinIO**: http://localhost:9090

### 2. Установка зависимостей Python

```bash
uv sync
```

### 3. Настройка окружения



Настройте переменные окружения при необходимости.

### 4. Установка моделей Ollama

```bash
# Основная LLM
docker exec -it ollama ollama pull qwen2.5:3b

# Эмбеддинг-модель (Nomic - для векторизации документов)
docker exec -it ollama ollama pull nomic-embed-text
```

## Запуск приложения

```bash
uv run main.py
```
